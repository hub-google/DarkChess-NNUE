# 01. 專案目標與架構總覽

## 一、 專案目標與挑戰

本專案旨在打造一款世界最強、且具備自我進化能力的暗棋（Banqi）人工智慧。為確保未來任何 AI 協作開發者皆能精準重現此系統，本需求書提供極度詳細的架構、資料格式與參數定義。

*   **硬體限制**：無 GPU 環境，必須完全依賴 CPU 運算（現已升級為分散式網頁前端叢集運算，動員至少 20 台機器共同平行計算）。
*   **領域挑戰**：暗棋屬於隨機型不完全資訊遊戲，先手翻牌運氣成分極重，且中盤存在大量未知機率節點。
*   **解決策略**：採用位元棋盤（Bitboard）極致優化 CPU 效能、NNUE 輕量化神經網路作為評估函數，並導入「強制同源鏡像對弈」來精準驗證棋力成長。

## 三、 開發時程建議

*   **第一階段 (基礎建設)**：完成 Bitboard 盤面表示、遊戲規則邏輯、殘局庫與隨機底盤生成器。
*   **第二階段 (演算法與驗證)**：實作 Star 搜尋演算法，並架設「鏡像交叉對戰」的驗證腳本與 SPRT 檢定系統。
*   **第三階段 (分散式前端與 UI)**：實作 GitHub Pages 人機對弈介面、Web Worker 背景對弈模組，以及串接 Bucket 的批次上傳機制。
*   **第四階段 (NNUE 與後端自動化)**：整合 NNUE 推論引擎，撰寫本地 Python 訓練迴圈，自動抓取 Bucket 資料進行訓練與發布，實現全自動掛機進化。
