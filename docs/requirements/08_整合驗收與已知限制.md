## 已修復／防護

1. 深搜超預算後取消預算、造成幾小時找不到落子的漏洞：移除無界 fallback，採合法公開資訊保底並標註 `qd=0`。
2. 初始翻牌搜尋未限時計算：明確節點／時間上限、失敗時 depth-zero 合法翻牌。
3. 無完成棋譜卻顯示工作成功：上傳時明確失敗；不合法、沒有終局的棋譜拒絕進 HF。
4. Policy 在 1024 種可能 move ID 上亂學：Binary cache 保留 **1024 位合法走法 bitset**，對稱擴增與 logits 遮罩同步，只從合法動作更新 Policy。
5. 資料庫消失與過期的網頁統計：重建原同名私人 HF repo、事件驅動公開統計及 Pages 更新。
6. 訓練過小 replay 污染模型：正式 train 至少 1000 局，必須通過配對 SPRT 的 H1 才晉升，並保存 `sprt_results.json`。
7. 缺外部基準造成自我對弈評估偏誤：獨立 MistyBanqi 比賽，同底牌交換身份，保存結果；比賽規則差異不隱藏。

## 明確尚未能宣稱完成的目標

- **世界第一暗棋 AI**：仍需對 CLAP_CDC、DarkKnight 等國際競賽強程式做規則一致、有統計信賴度的正式長賽。目前沒有此證據。
- **真正同一份 Rust/WASM/ Python 搜尋核心**：目前外部 Rust 競技場是獨立程式；瀏覽器有 TS 受限機率搜尋；訓練端有 Python Star1，它們尚非完全相同的原生共享核心。若宣稱已完成就是不實。
- **正式模型的持續棋力上升**：要等生產 Self-play 累積到最小 1000 局、train Action 跑完並通過 SPRT；目前並未自動產生比舊 Champion 強的證據。
- **大量外部棋力評測**：第二版 `external_arena.yml` 提升到每候選 20 對 40 局，仍無法代表世界級長賽或完全排除引擎棋規差異。
- **歷史資料復原**：舊 HF Repository 不再能存取時，不應捏造可恢復的舊 replay。
- **整合後的 Pages 手動瀏覽器體驗驗收**：GitHub Pages workflow 成功證明資產已發布，未執行真實裝置跨瀏覽器互動的人工 UAT。
