# 第二代研究原型（非正式引擎）
本目錄不影響 master、冠軍或現有部署。
- movegen.cpp：32 格位元棋盤基本走法原型（翻子、移動、炮、兵將特例）。**尚未包含長追與終局歷史**，不能用於正式下棋。
- corpus.cjs：固定種子，從舊引擎合法實際走棋產生公開盤面；排除有 pendingChase 的位置。輸出 TS 完整走法集合及原型等價測試資料，不包含底牌。另記錄 TS 走法生成吞吐。
- audit.py：只讀 HF 已整併資料，統計全量 ID、標籤、版本及結果，固定雜湊選樣合法重播；不刪資料、不上傳 HF。抽樣不能證明全部合法，更不能證明訓練價值。
- GitHub Actions 暗棋 V2｜基準與資料稽核：手動或 research-v2 推送觸發，輸出 artifacts；不進行冠軍升級、網站部署或連續自我對弈。
- 原型的走法微基準只可用來判斷是否值得繼續移植，不能推論完整搜尋速度或棋力。
