# V2 原生 CPU 公開棋盤與增量 NNUE
獨立 C++20 研究核心，不讀取真實底牌，只接受裁判提供的合法翻牌結果。
- board.hpp：位元棋盤走法、長追路線、棋子識別、剩餘暗子、終局、60 手和局與重複局面特徵。
- nnue.hpp：舊冠軍 498→256→32→1 權重格式，第一層累加器以特徵差值更新；第二/三層完整計算。
- corpus.cjs / parity.cpp：比較 TS 逐手狀態、走法、長追、重複、終局、估值與增量/完整推論差異。先用 Node loader 驗證正式模型 SHA，再讀同一份權重。
此階段不等於正式搜尋器，尚未完成低成本撤銷、置換表、SIMD 性能驗證及 WASM。資料集屬研究測試，不能作外部棋力證據。
